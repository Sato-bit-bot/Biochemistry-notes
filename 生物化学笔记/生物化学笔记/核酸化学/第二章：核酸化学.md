## 一、名词解释

### 1. 增色效应（hyperchromic effect）

DNA 等双链核酸**变性**时，双螺旋被破坏，碱基对之间的**碱基堆积作用**消失，碱基充分暴露于溶剂，使其在 **260 nm** 处的紫外吸收值**升高**，这一现象称为增色效应。

- 通常 A₂₆₀ 升高约 **25%～40%**（各教材取值不一，多为"约 30%"）。
- 本质：吸收紫外光的生色团是**碱基**；游离核苷酸的 A₂₆₀ 高于等量天然双链 DNA。堆积使吸收下降（减色），堆积瓦解即表现为增色。
- 用途：绘制熔解曲线、追踪变性程度、检查核酸纯度（A₂₆₀/A₂₈₀）。

### 2. 减色效应（hypochromic effect）

与增色效应方向相反。**变性的单链核酸复性、重新形成双螺旋**时，碱基重新堆积，260 nm 紫外吸收值**降低**并回落到天然双链的水平，称为减色效应。

- 等价表述：天然双链 DNA 的 A₂₆₀ 比其等量游离核苷酸（或完全变性的单链）低约 30%～40%，这种"因形成双螺旋而吸光下降"的性质即减色效应（hypochromicity）。
- 提示：增色效应与减色效应是同一物理现象的两个方向，考题常成对出现。

### 3. DNA 复性（renaturation）

变性 DNA 在适当条件下，两条互补单链重新缔合，恢复原来的双螺旋结构（及部分或全部生物学活性）的过程，又称**退火**（annealing）。

条件与规律：

- **温度**：缓慢降温；最适复性温度约为 **Tm − 25 ℃**（降温过快易形成错配）。
- **离子强度**：需一定盐浓度（如 0.15～0.5 mol/L Na⁺）以屏蔽磷酸骨架的静电斥力；离子强度过低则不易复性。
- **pH**：中性附近。
- 复性速度与 DNA 起始浓度、序列复杂度（重复序列快，单一序列慢）、片段长度、保温时间有关。
- 定量描述用 **Cot 曲线**（c₀ 为起始浓度，t 为时间）。

补充：变性—复性是**分子杂交**的理论基础；不完全复性可形成部分双链或错配双链。

### 4. 分子杂交（molecular hybridization）

利用核酸的**变性与复性**性质，使**来源不同**但序列互补的两条单链（DNA–DNA 或 DNA–RNA）在适当条件下按碱基互补配对结合，形成**异源双链（杂交分子）**的过程。

- 前提：两链之间存在互补序列；互补程度越高，杂交分子越稳定（Tm 越高）。
- 主要应用：Southern 印迹（DNA–DNA）、Northern 印迹（DNA–RNA）、斑点杂交、原位杂交、DNA 芯片、PCR 探针，以及用 DNA–DNA 杂交程度判断物种亲缘关系。
- 杂合分子的检测：羟基磷灰石（HAP）柱层析、S1 核酸酶消化未配对的单链部分。

### 5. 回文结构（palindrome）

DNA 双链中的一种对称序列：**两条链各按 5′→3′ 方向阅读时，序列完全相同**。

特征：

- 序列的两半**互为反向互补**（reverse complement），即整条序列是自身的反向互补序列。
- 存在一个假想的**中心对称轴**，绕该轴旋转 180° 后两条链完全重合，故又称**二重（旋转）对称**。
- 同一条链内可因互补而回折，形成**发夹结构**；双链可形成**十字结构**（cruciform）。
- 常为**限制性内切核酸酶**的识别位点（如 EcoRⅠ 识别 GAATTC），也是原核生物不依赖 ρ 因子的转录终止子结构。

教材示例（两链 5′→3′ 读出的序列相同）：

```
5′-T T A G C A C G T G C T A A-3′
3′-A A T C G T G C A C G A T T-5′
```

### 6. 镜像重复（mirror repeat）

DNA 中的另一种对称序列：**同一条链正读（5′→3′）与反读（3′→5′）序列相同**，即序列的两半**互为反向**（reverse，而非反向互补）。

特征（与回文结构对照）：

- 两条链各按 5′→3′ 阅读时，序列**互补**而不是相同；两链从正向、反向阅读其意义相补。
- 同样存在假想的中心轴，但绕该轴旋转 180° 后两条链**互补而无法重合**（故称"镜像"）。
- 属**颠倒重复**；**不能形成发夹结构**（链内无法互补配对）。

教材示例（上行正读、反读均为 TTAGCACCACGATT）：

```
5′-T T A G C A C C A C G A T T-3′
3′-A A T C G T G G T G C T A A-5′
```

**回文结构与镜像重复对照表**

| 比较项 | 回文结构 | 镜像重复 |
| --- | --- | --- |
| 序列两半的关系 | 反向**互补** | 反向（非互补） |
| 两链 5′→3′ 读出的序列 | 相同 | 互补 |
| 绕中心轴旋转 180° | 两链重合 | 互补但**不重合** |
| 能否形成发夹 / 十字结构 | 能 | 不能 |

> 术语提醒：「镜像重复」在不同教材中定义并不统一（有的书与"反向重复序列"混用）。上表按巫光宏 / 黄卓烈教材体系整理，请以你书上表述为准。

### 7. Watson–Crick 配对

即 **A–T（A–U）、G–C 的碱基互补配对**规则，是 Chargaff 规则的分子基础。

- A 与 T 之间形成 **2 个氢键**；G 与 C 之间形成 **3 个氢键**（故 GC 含量高的 DNA 更稳定、Tm 更高）。
- 配对发生在两条**反向平行**的糖–磷酸骨架之间；嘌呤配嘧啶使碱基对宽度恒定，保证双螺旋直径约 2 nm。
- 碱基对平面垂直于螺旋轴，相邻碱基对间距 0.34 nm、相对旋转 36°（B-DNA 每圈 10 bp）。
- 是 DNA 复制、转录、分子杂交的分子基础。

### 8. Hoogsteen 配对

在 Watson–Crick 配对之外的一种**非经典碱基配对**：嘌呤碱基绕糖苷键翻转，改用 **N7 位**（腺嘌呤另有 N6–H、鸟嘌呤另有 O6）这一侧的面（Hoogsteen 面）与嘧啶碱基形成氢键。

- 典型形式（第三个碱基与 Watson–Crick 碱基对中的嘌呤配对）：
  - 嘧啶型：**T·A=T**、**C⁺·G≡C**（胞嘧啶需 N3 质子化，故需偏酸条件）
  - 嘌呤型：A·A=T、G·G≡C（反式 Hoogsteen）
- 出现场合：**三链 DNA（H-DNA）**、**G-四链体**、tRNA 的 TψC 环与 D 环相互作用、部分 RNA 三级结构。
- 意义：使第三条链能够识别双螺旋中的碱基对，是三链核酸形成、反义寡核苷酸设计与 G-四链体稳定的结构基础。

### 9. DNA 双螺旋（DNA double helix）

Watson 与 Crick 于 1953 年提出的 DNA 二级结构模型（依据 Franklin、Wilkins 的 X 射线衍射数据；1962 年获诺贝尔生理学或医学奖）。

**B-DNA（生理条件下的主要构象）：**

- 两条**反向平行**的多核苷酸链围绕同一中心轴盘绕成**右手螺旋**；
- 亲水的磷酸–脱氧核糖骨架在**外侧**，碱基对在**内侧**；
- 直径约 **2 nm**，每圈 **10 个碱基对**（溶液中约 10.5），螺距 **3.4 nm**，相邻碱基对间距 **0.34 nm**，相邻碱基对夹角 **36°**；
- 表面形成**大沟**（major groove）与**小沟**（minor groove），是蛋白质识别 DNA 的部位。

**稳定因素：**① 碱基对之间的氢键（横向）；② **碱基堆积力**（纵向疏水作用与范德华力，是主要因素）；③ 环境中的阳离子与水屏蔽磷酸基的静电斥力。

**其他构象：**A-DNA（右手、较宽扁、11 bp/圈）、Z-DNA（**左手**螺旋、骨架呈锯齿状、富 GC 交替序列、12 bp/圈）。

### 10. DNA 超螺旋（supercoiling）

在共价闭合环状 DNA（cccDNA）或两端固定的线状 DNA 中，双螺旋不能自由旋转，**额外的螺旋张力**只能通过双螺旋轴本身在空间再度盘绕来释放，由此形成的结构即超螺旋。

- 拓扑学描述：**Lk = Tw + Wr**（连接数 = 扭转数 + 缠绕数）；Lk 只有在链断裂并重新连接时才能改变。
- **负超螺旋**（欠旋，Lk < Lk₀）：螺旋轴以左手方式盘绕，有利于双链解开；**生物体内的 DNA 以负超螺旋为主**，超螺旋密度 σ ≈ −0.05～−0.07（约每 200 bp 一个负超螺旋）。
- **正超螺旋**（过旋，Lk > Lk₀）。
- 生物学意义：负超螺旋储存的自由能使 DNA 更易解链，利于复制、转录、重组与包装。
- 相关酶：**拓扑异构酶Ⅰ**（切断一条链，ΔLk = ±1，不耗 ATP）；**拓扑异构酶Ⅱ / DNA 旋转酶**（切断双链，ΔLk = ±2，耗 ATP；细菌 DNA 旋转酶引入负超螺旋）。

### 11. 核酶（ribozyme）

具有**催化活性**的 RNA，即 RNA 分子本身（而不是其中的蛋白质）能催化化学反应。

- 发现：1982 年 Cech 发现四膜虫 rRNA 前体的**自我剪接**（Ⅰ类内含子）；Altman 发现 RNase P 的 RNA 组分具催化活性；二人共获 **1989 年诺贝尔化学奖**。
- 常见类型：Ⅰ类 / Ⅱ类自我剪接内含子、**锤头核酶**、**发夹核酶**、丁型肝炎病毒（HDV）核酶、RNase P 的 RNA 组分、**核糖体**（肽基转移酶中心由 rRNA 构成，故核糖体本身是一种核酶）、剪接体（snRNA 起催化作用）。
- 特点：多为分子内（顺式）切割或连接反应，常需 Mg²⁺ 等二价金属离子；催化效率一般低于蛋白酶。
- 意义：为"**RNA 世界**"假说提供了重要证据。

## 二、易混点复习

1. **增色 ↔ 减色**：方向相反，都围绕 260 nm 紫外吸收与碱基堆积作用。
2. **变性 ↔ 复性**：变性只破坏氢键和碱基堆积力，**不破坏磷酸二酯键**（一级结构不变）；Tm 与 GC 含量正相关。
3. **回文结构 ↔ 镜像重复**：判别口诀——"两链同读相同是回文，一链正反相同是镜像"。
4. **拓扑异构酶Ⅰ ↔ Ⅱ**：切一条链 vs 切两条链；ΔLk = ±1 vs ±2；不耗 ATP vs 耗 ATP。
5. **Watson–Crick ↔ Hoogsteen**：前者用嘌呤的 N1/N6（A）或 N1/O6（G）面，后者用 N7 面。
