## 二、繁殖方式

硅藻共有四种繁殖方式：

### 1. 营养生殖（细胞分裂）

- 硅藻**最普遍**的一种繁殖方式，一般在**夜间**进行。
- 过程：开始原生质略膨大 → 核分裂 → 原生质一分为二 → 两核分别靠近**上下两壳** → 每一半壳各自长出一个**新的下壳**，形成新个体。
- 刚形成的壳薄，以后逐渐增厚，直至与母壳相等。
- 意义：这一机制导致细胞逐代变小，需靠复大孢子恢复大小。

### 2. 复大孢子生殖

当细胞分裂到一定大小后，在某种环境下可产生一种孢子，以**恢复到原来大小、增强生命力**，这种孢子称**复大孢子（auxospore）**。

**（1）无性方式**

- 由营养细胞的**两壳直接脱开**，原生质裸出，继续长大，近似球形，成为复大孢子；体积增大到正常时停止，分泌细胞壁，形成新个体。
- 在**环壳的侧部**发生一个小的椭圆形小孔，细胞内容物通过小孔流出壳外形成球状，附着于孔部成为球块，形成一个复大孢子，然后长出新的细胞壁。

**（2）有性方式**

- 由两个细胞各自进行**减数分裂**产生两个配子，含有两个核，其中一个核消失。
- 不同细胞产生的配子彼此成对结合，成为**两个复大孢子**；孢子萌发，形成新个体。

### 3. 小孢子

- 多见于**中心硅藻**的一种生殖方式。
- 细胞核和原生质多次分裂，形成 **8、16、32、64、128** 个小孢子。
- 每个孢子具 **1–4 条鞭毛**，长成后成群逸出，相互结合为**合子**，然后每个合子发育成为新个体。

### 4. 休眠孢子

- 细胞内原生质收缩，聚集于中央，然后分泌**厚壳**包围，壳上常有**刺状突出物**。
- 当环境有利时，萌发恢复原有形态和大小。
- 为**沿岸性的中心硅藻**的一种生殖方法。

## 三、中心硅藻纲的分类

分类特征层级：

- **细胞主体**为一级分类特征；
- **细胞突出物**为二级分类特征。

| 细胞形态 | 特征 | 所属目 |
| --- | --- | --- |
| 圆盘形、鼓形 | 无角状突起 | **圆筛藻目**（Coscinodiscales） |
| 长圆柱形 | 具长角 / 棘刺 | **根管藻目**（Rhizoleniales） |
| 小盒形 | 具两个以上明显的圆形隆起或角状突起，具长棘刺 | **盒形藻目**（Biddulphiales） |

| **小环藻** *Cyclotella* | 单细胞，少数情况下壳面连接成直的或螺旋链状群体；细胞圆盘形或鼓形；壳面圆形、少椭圆形，常具同心圆或与切线平行的波状皱褶，边缘带放射状排列的孔纹或线纹，中央平滑或具放射状孔纹；带面平滑，无间生带；色素体小盘状、多数 | **中央与边缘花纹不同、明显断开**为其特点 |
| **圆筛藻** *Coscinodiscus* | 细胞圆盘形，壳面圆形、少椭圆或不规则，平或波曲状；壳缘周边具小棘；花纹为细点纹至网眼纹，自中心向壳缘放射状或不规则排列；带面常具间生带；色素体小盘状多数或 2 块片状 | 孔纹一般六角形，正中心有时特别粗大似玫瑰花朵排列，称**中央玫瑰区**；正中心小块无纹区称**裂隙**，较大时称**中央无纹区**；壳缘部分称外围，最外围孔纹间常有一圈小刺 |
| **骨条藻** *Skeletonema* | 海产；细胞透镜形、短圆柱形，壳面圆形少椭圆，壳面仅一层孔纹或点纹；细胞靠**支持突外管（缘刺）**相连成整齐链状群体 | 细胞直径 6–7 µm，壳面圆而鼓起，细胞间靠细刺组成长链，刺数 8–30 条，细胞间隙长短不一但比细胞本身长；壳面点纹极微细不易见；可作养殖饵料，也会大量增殖形成**赤潮** |
| **海链藻** *Thalassiosira* | 细胞圆盘状，靠中央的**胶质丝**相连成松散链状群体，或包埋在自身分泌的胶质块内，少数单独生活；壳面具有一个**中央突**和多个**支持突** | 此属多为**污水种类**，常在夏季静水区形成水华；间生带明显，呈环纹状或领纹状，壳缘有许多小刺 |
| **冠盖藻属** *Stephanopyxis* | 细胞壳面圆形、略鼓起；壳缘着生**一圈管状刺**，以此连成短链；细胞壁有明显的**六角形孔纹**，无间生带 | |
| **细柱藻属** *Leptocylindrus* | 细柱藻科：细胞**长圆柱形**，以壳面紧密相连构成细长链状群体，链直或波状弯曲；壳面无刺无突起；细胞壁薄、无花纹；色素体 2 个或多个，颗粒状或圆板状 | 我国只一种——**丹麦细柱藻** *L. danicus*，细胞直径 8–12 µm，长 31–130 µm，长为宽的 2–12 倍，色素体颗粒状 6–33 个 |
| **根管藻** *Rhizosolenia* | 单细胞或少数细胞连成暂时性群体；壳面圆形或椭圆形、舟形，顶端具**长棘刺**；细胞壁薄、轻度硅质化、透明，具细点纹；常具多数**鳞片状、环状或领状间生带**，带面延长呈长圆柱形；色素体多数，小颗粒或小盘状 | 间生带形态为重要识别点 |
| ***Acanthoceras* / 四棘藻 *Attheya*** | 细胞**扁圆柱形**，壳面扁椭圆形，中部凹入，两端各具 **2 条粗长的刺状突起**；细胞壁极薄，显微镜下近似透明；带面长方形，具许多环状间生带；色素体小盘状 2–4 个 | **富营养型湖泊**常见的浮游种类 |
| **盒形藻** *Biddulphia* | 单细胞或以刺毛或突起相连成疏松群体；外形为**小盒状或布袋状**；刺毛短于细胞，若长于细胞则有爪，或无刺毛而有突起 | 细胞形似一袋面粉或近圆柱形；壳面一般椭圆形，两端有突起，突起末端常有小型真孔分泌胶质，使细胞连成直链或锯齿状群体 |
| **角毛藻** *Chaetoceros* | 壳面椭圆形，少数圆形；细胞以**角毛相连成链**（刺毛长于细胞，**毛端无爪**）；细胞壳面构造极微细精致，一般不易看清；色素体数目、形状、大小、位置随种类而异，**是分类的主要依据** | **赤潮种**，刺对鱼虾贝类的鳃可产生机械损伤 |
| **双尾藻属** *Ditylum* | 单细胞，三角形、柱形、四角柱形或圆柱形；壳面中央有一条**粗直中空的长刺**，与贯壳轴平行；有的种类壳面四周有许多小刺；壳环面长短随间生带多少而改变；细胞壁薄，花纹不明显 | |
| **漂流藻属** *Planktoniella* | 单细胞，细胞**圆盘形**，壳环面四周有薄而透明的**翼状突**，翼上有许多射出肋，有支持翼状突及有利漂浮的作用 | 本属只有 2 种，我国仅 **1 种——太阳漂流藻** *Planktoniella sol*，分布南海、东海、南黄海，为**暖水性种** |
| **三角褐指藻** *Phaeodactylum tricornutum* | 细胞卵形、梭形或三角形；卵形细胞有一个和桥弯藻相似的硅质壳面，**缺少另一壳面，也无壳环带** | 被广泛作为培养对象，是实验生态学良好材料，也是鱼、虾、贝幼体的良好饵料 |

## 五、生态分布与意义

本章从三方面论述：

1. 硅藻的饵料意义
2. 常见赤潮硅藻简介
3. 硅藻的工业价值

### 5.1 饵料意义

- 硅藻是**海洋有机物的主要生产者之一**，与其它浮游植物一起构成海洋**初级生产力**。
- 硅藻是海洋动物及其幼体的直接或间接饵料；在我国沿海**贝类的饵料中硅藻占首要地位**。
- 海洋浮游甲壳动物以及对虾和其它经济虾类的幼体等，也都以硅藻为主要摄取对象。
- **中国毛虾**的全年食物中，硅藻占 **54%**；沙丁鱼等幼鱼也以硅藻为主要食物。
- 因此，**海洋经济动物产量的高低与硅藻的数量密切相关**。
- 随着海水养殖业发展，人工大量培养硅藻（如**中肋骨条藻、三角褐指藻、牟氏角毛藻、新月菱形藻**等）以解决经济海产动物人工育苗幼体的饵料，是提高单产必不可少的技术关键。

### 5.2 常见赤潮硅藻

- 海洋环境若受到**富营养污染**或其它原因，常使某些硅藻（骨条藻、菱形藻、盒形藻、角毛藻、根管藻、海链藻等）**生殖过盛形成赤潮**，使水质恶劣，对渔业及其它水产动物带来严重危害。
- 有些硅藻（如根管藻）生殖太盛并密集在一起，可**阻碍或改变鲱鱼的洄游路线**，降低渔获量。

### 5.3 工业价值

- 硅藻死亡后的**硅质外壳**大量沉积海底，经 **1 至 2 万年**左右的堆积期，形成化石性的硅藻堆积土，称为**硅藻土**（diatomaceous earth），含 **83.2% 的氧化硅**。
- 工业用途很广：建筑、磨光等材料，过滤剂、吸附剂，造纸、橡胶、化妆品和涂料的**填充剂**，以及**保温材料**等。
- 化石硅藻对石油勘探有关的地层鉴定，以及对古地理的研究都有一定的参考价值。
