## 一、分类地位与概述

- 头足纲属 **软体动物门（Mollusca）**，是其中**最高等、最特化**的类群，也是唯一能进行**快速游泳**的类群。
- 现存约 **800 余种**，全部海生，从潮间带至数千米深海均有分布。
- 主要进步特征（与其它纲相比）：
  1. 身体**两侧对称**（软体动物中最典型的两侧对称类群）；
  2. **头部发达**，具高度进化的眼；**足与头部愈合**，特化为口周围的**腕**（和触腕）——故称「头足类」；
  3. **外套膜肌肉质**发达，与头部借结缔组织紧密愈合形成**密闭的外套腔**，经**漏斗**与外界相通，构成喷水推进装置；
  4. **内壳退化**（乌贼骨、角质内壳）或完全消失，仅鹦鹉螺保留外壳；
  5. **闭管式循环**，血蓝蛋白为呼吸色素；
  6. **神经系统在软体动物中最发达**，脑被软骨质头软骨包围，具巨轴突；
  7. **眼具晶体与视网膜**（与脊椎动物趋同进化）。

## 二、外部形态

头足类身体可分为 **头部、足部（腕）、躯干（外套膜）** 三部分，另具 **漏斗、鳍** 等衍生物。

### 2.1 头部

- 发达，与躯干部之间以**颈部（缘膜 collar）** 为界。
- **眼 1 对**：着生于头部两侧，除鹦鹉螺为孔眼外，其余均具**角膜、晶体、视网膜**，结构与脊椎动物趋同；但视神经纤维自感光细胞背面穿出，**无视神经乳头（无盲点）**。
- **口**：位于头部前端中央的**口球（buccal mass）** 内。
  - **颚片 1 对**：几丁质，形似**鹦鹉喙**（角质喙），上下咬合，用以撕碎猎物。
  - **齿舌（radula）**：位于颚片之间，具多列细齿，锉碎食物——软体动物的典型特征在此仍保留。

### 2.2 足部——腕与触腕

- 足环列于口周围，向前方延伸分化为 **8 条腕**；十腕类另有 **2 条特化的触腕（tentacular club）**，可伸缩捕食。
- 腕上密生**吸盘**：
  - 吸盘具**柄**（柄吸盘）或无柄；
  - 吸盘边缘具**角质环**，乌贼目角质环常具**小齿**，用以抓握猎物；
  - 吸盘的排列式为**分类依据**之一。
- 腕间常有**腕间膜**相连，章鱼腕间膜发达，游泳时呈伞状。用于捕食
- **茎化腕（hectocotylus）**：雄性一侧的一条腕特化，用以向雌性传递**精荚**（见生殖系统）。

### 2.3 躯干与外套膜

- **外套膜**为肥厚的肌肉质囊，包被内脏团；背面常形成**胴部**，表面色素丰富。
- 外套膜与头部借结缔组织**紧密愈合**，围成**密闭的外套腔**（仅漏斗孔通外界）——这是喷水推进的结构基础；水由**入水孔**进入外套腔，经外套膜收缩再从**漏斗**喷出。
- **喷水孔（pallial pore）**：乌贼目外套膜背面有 1 对出水孔，可作辅助排水通道。

### 2.4 漏斗（funnel / hyponome）

- 位于头部腹面、口的后方，由**足的基部**特化形成的**管状结构**，是**外套腔的出口**。
- 功能：**喷水推进**（运动）、**排泄**（肛门、肾孔、墨管开口于外套腔，废物随水流经漏斗排出）、**喷墨**。
- 漏斗可**左右摆动**改变喷水方向；乌贼等具**漏斗锁（funnel locking apparatus）**：漏斗背面的凹槽与外套膜内面的锁突互相嵌合，喷水时锁定漏斗，使喷射有力、方向稳定——快速逃逸的结构基础。

### 2.5 鳍

- 由外套膜特化的**肌肉质薄膜**，司**游泳平衡与辅助运动**。
- 形状位置与习性相关：
  - **乌贼目**：鳍沿胴部**两侧全长**延伸（周鳍型），波动式游泳，灵活但速度中等；
  - **枪乌贼 / 柔鱼**：鳍位于胴部**后端**，多呈**三角形**（端鳍型），适于高速巡航；
  - **耳乌贼**：鳍呈耳状，位于胴部后端两侧；
  - **章鱼**：多数无鳍（底栖爬行），少数种类（如船蛸）具耳状鳍。

### 2.6 内壳（退化程度是重要分类特征）

| 类群   | 内壳形态                              | 成分      | 功能                          |
| ---- | --------------------------------- | ------- | --------------------------- |
| 鹦鹉螺  | **外壳**，分室，具隔壁与体管                  | 碳酸钙（文石） | 保护 + **浮力调节**（气室气体比例经渗透调节）  |
| 乌贼目  | **乌贼骨（cuttlebone）**：石灰质椭圆板，具气室与横隔 | 碳酸钙     | 支撑 + **浮力调节**（调节气液比例，助垂直迁移） |
| 管鱿目  | **角质透明内壳（gladius / pen）**：羽状薄片    | β-几丁质   | 纵向支撑、附着肌肉                   |
| 耳乌贼目 | 小型角质内壳，多退化                        | 几丁质     | 弱支撑                         |
| 章鱼目  | 退化为**细小薄片**或**完全消失**              | 几丁质     | 几无功能（底栖爬行不需硬支撑）             |

> 演化趋势：**外壳 → 内壳 → 内壳退化 / 消失**，与运动方式由被动防护转向主动逃避相一致。

## 三、内部构造

### 3.1 肌肉与支持

- 外套膜与胴部为**发达的横纹肌**，收缩产生喷水动力；头足类肌肉占体重比例大，故肉质厚实。
- 具**软骨质头软骨（cephalic cartilage）** 包围脑，另有腕软骨、颈软骨等支持结构——软体动物中唯一具成形软骨支撑的类群（近似内骨骼雏形）。

### 3.2 消化系统

**口 → 口球（颚片、齿舌）→ 食道 → 嗉囊 → 胃（砂囊）→ 盲囊 → 直肠 → 肛门**

- **肛门**位于头部下方、外套腔内（口的后方），食物残渣排入外套腔，经漏斗喷出。
- **嗉囊（crop）**：暂时贮存食物。
- **胃**：肌肉壁发达，内壁具**角质胃磨**，进一步研磨食物；部分种类胃壁肌肉形成砂囊样结构。
- **肝胰腺 / 胃盲囊（digestive gland）**：最大的消化腺，分泌消化液通入胃与盲囊，是主要的**消化吸收场所**，兼有贮存功能。
- **唾液腺**：分泌物含**神经毒素**，注入猎物可使其迅速麻痹——头足类为凶猛肉食者。
- **墨囊（ink sac）**：
  - 外套腔背壁的盲囊，内储**黑色墨汁**（黑色素、儿茶酚胺、铵盐、肽类等）；
  - **墨管开口于直肠末端（肛门附近）**，喷墨时墨汁混入漏斗水流一同喷出；
  - 功能见生理部分（防御烟幕 + 味觉 / 嗅觉干扰）。

### 3.3 呼吸与循环系统

**呼吸——鳃**

- 位于外套腔内，**羽状鳃**，密布血管；二鳃总目 **1 对**，鹦鹉螺 **2 对**。
- 鳃基部具**嗅检器（osphradia）**，化学感受器，检测水流中的化学物质。
- 鳃心（腹心）位于鳃基部，推动静脉血入鳃完成气体交换。

**循环——闭管式循环**

- 头足类是软体动物中唯一具**闭管式循环**的类群：血液始终在血管内流动，动静脉不直接相通，交换效率高，与其高代谢、快速运动相适应。
- 组成：
  - **体心（systemic heart）1 个**：将含氧血送往全身；
  - **鳃心（branchial hearts）1 对**：位于鳃基部，将静脉血**压入鳃**；
  - 鹦鹉螺具 **2 对心**（2 体心 + 2 鳃心），与 2 对鳃对应。
- **呼吸色素**：**血蓝蛋白（hemocyanin）** 溶于血浆，含铜，氧化时呈**蓝色**（头足类血液为淡蓝色），在低温、低氧海水中携氧有效。

### 3.4 排泄系统

- **肾（肾管）1 对**，位于围心腔两侧，开口于外套腔，排泄物以**鸟嘌呤**结晶为主（随水流经漏斗排出）。
- 鳃心表面亦具**排泄功能**（部分种类鳃心外壁有排泄小管，可排出部分代谢废物）。

### 3.5 神经系统（软体动物中最发达）

- **中枢**：脑由食道周围的**神经节环**组成，外包**头软骨**保护；分为前脑、中脑、后脑三部分：
  - **前脑**：嗅叶、视神经节，支配感觉；
  - **中脑**：足神经节，支配腕与运动协调；
  - **后脑**：脏神经节，支配内脏。
- **巨轴突（giant axon）**：直径可达 1 mm 的特化神经纤维，传导速度极快，介导**喷水逃逸反射**（外套膜快速强力收缩）——神经生物学经典实验材料（Hodgkin、Huxley 据枪乌贼巨轴突建立动作电位离子学说，获 1963 年诺贝尔奖）。
- **腕神经节**：每条腕基部具神经节，腕可**相对独立地完成复杂动作**（如取食、探索），有「分散式大脑」之说；章鱼断腕后短时间内仍能活动。
- **腹神经索**已高度愈合、集中化，与自由生活、快速运动相适应。

### 3.6 感官

- **眼**：具角膜、晶体、视网膜，能成像、辨色（多数种类具色觉）；视网膜感光细胞朝外（与脊椎动物相反），**无盲点**。
- **平衡囊**：1 对，位于头部，内有**耳石**，感知身体方位与平衡。
- **嗅检器**：鳃基部，化学感受（觅食、报警）。
- 部分深海种类具**发光器**（共生发光菌或自身发光），用于照明、诱饵、反照明伪装与种内通讯。

### 3.7 生殖系统（雌雄异体，异形）

**雄性**

- 精巢（1 个，位于体后部）→ 输精管 → **精荚囊**（贮存**精荚 spermatophore**）→ 交接腕输出。
- **茎化腕**：一条腕特化（如章鱼右第 3 腕、乌贼左第 4 腕），具特殊吸盘或凹槽，交配时将精荚送入雌体外套腔内；船蛸等种类茎化腕交配后**脱落**留于雌体。

**雌性**

- 卵巢（1 个）→ 输卵管 → **缠卵腺（nidamental gland）**：分泌物质包裹受精卵，形成卵膜 / 卵鞘（乌贼的缠卵腺发达，产出的卵具黑色卵膜、附着于海底基质）。
- 部分种类具**副缠卵腺**、**输卵管腺**等附属腺体；章鱼卵成串悬挂于巢穴中孵化。
- **纳精囊**：贮存交配所得精子，行**体内受精**。

## 四、生理特征

### 4.1 运动生理——喷射推进

- **外套膜舒张**：外套腔经入水孔（或外套膜缘缝隙）进水，腔内低压；
- **外套膜强力收缩**：腔内水压骤升，水经**漏斗**高速喷出，反作用力推动身体**后退**（漏斗朝前喷则身体后退，朝后喷则前进，可灵活转向）；
- **鳍波动**：缓游、升降与姿态平衡；
- **腕泳**：部分种类（如飞鱿、某些章鱼）张开腕间膜滑翔。
- 特点：**间歇性爆发式**运动，速度极快（柔鱼瞬时速度可达数十 km/h），但**乳酸积累快、易疲劳**，需间歇恢复——故多为「伏击 + 逃逸」型。

### 4.2 呼吸生理

- 水流由外套腔进出，不断流经鳃丝 → 血液与水在鳃处**逆流交换**（部分种类），气体交换效率高。
- 代谢率高，耗氧量大，需持续通水；这也是漏斗必须高效的原因之一。

### 4.3 色素调节与拟态（神经-体液控制）

- 皮肤具**色素细胞（chromatophores）**：每个色素细胞外包**放射状肌**，肌收缩则色素囊摊开显色，肌松弛则色素点缩小褪色——由**神经直接控制**，反应速度达**毫秒级**（是动物界最快的变色系统之一）。
- 色素细胞下另有**虹彩细胞（iridophores）**（结构色，产生金、绿、蓝金属光泽）与**白色细胞（leucophores）**（漫反射环境光），三层配合实现**拟态、警戒、种内通讯**（如求偶、威吓的体色图案）。
- 头足类因此被称为「**会说话的皮肤**」；章鱼、乌贼的变色伪装是行为生态学研究热点。

### 4.4 墨囊防御生理

- 受惊时外套膜收缩，墨汁经漏斗喷出，形成**「墨幕（pseudomorph）」**——外形与本体相似的墨团，诱使捕食者攻击假目标。
- 墨汁成分含**黑色素、儿茶酚胺（肾上腺素类）、铵盐**等：
  - 视觉遮蔽（烟幕）；
  - **麻痹捕食者嗅觉 / 味觉**（干扰化学感觉），延长躲避时间；
  - 鹦鹉螺**无墨囊**，是原始特征。

### 4.5 生殖生理与发育

- **体内受精**，雌雄异体；精荚经茎化腕传递。
- **卵大、卵黄多**，为**螺旋卵裂、直接发育**（无担轮幼虫期、无面盘幼虫期）：孵化出即为**微型成体**（幼体阶段缩短）。
- **生长快、寿命短**：多数种类 1–2 年生（大型鱿鱼 1–2 年，章鱼多 1–3 年），**性成熟后繁殖一次即死亡**（一次繁殖 / semelparity）——能量分配上「快生快死」的r-选择策略。
- 繁殖期雌性护卵（章鱼守巢、扇水增氧），护卵期间常**停止摄食**，孵出后死亡。

### 4.6 神经生理——逃逸反射

- 感觉（眼、嗅检器）→ 脑 → 巨轴突 → 外套膜肌快速同步收缩 → 漏斗喷水，全套反射在**几十毫秒**内完成。
- 巨轴突的**全或无动作电位、跳跃式传导**使逃逸成为软体动物中最快的反应之一。

### 4.7 渗透压与深海适应

- 多数头足类为**渗透压随变者（osmoconformer）**，体液渗透压与海水接近，不主动耗能调节。
- 深海种类具**氨 / 鳍铵离子积累**降低组织密度（近中性浮力）、发光器反照明、降低代谢等适应。
- 乌贼骨 / 鹦鹉螺气室是**静力学浮力装置**：通过调节气室中气体与液体比例获得近乎中性浮力，实现**不耗能悬浮**与**垂直迁移**。

## 五、形态构造与生态习性的关系

| 生活方式 | 代表类群 | 形态 / 构造适应 |
| --- | --- | --- |
| **大洋表层快速游泳** | 柔鱼、枪乌贼 | 体型呈**流线型（纺锤形）**；**端鳍三角形**、面积大；角质内壳薄而轻；肌肉爆发力强；发光器反照明 |
| **近海底栖爬行 / 藏匿** | 章鱼、耳乌贼 | **无鳍或鳍退化**；腕多而强壮、吸盘发达，腕间膜用于爬行与**抱持贝壳伪装**；内壳退化（柔软可挤入缝隙）；色素拟态极发达 |
| **中层垂直迁移** | 乌贼、部分鱿 | **乌贼骨浮力装置** + 周鳍波动，节省能量地悬浮与升降 |
| **底栖穴居** | 部分耳乌贼 | 体型小、鳍耳状，可**用鳍挖掘泥沙**埋身伏击 |
| **深海** | 深海鱿、小飞象章鱼 | 发光器、大眼、降低代谢、氨积累近中性浮力；多为胶质松弛体壁 |

**核心权衡**：壳的退化 → 防护下降，换取**运动速度与灵活性**；补偿机制 = **喷射逃逸 + 墨幕 + 变色拟态 + 高级神经行为**。

## 附：核心逻辑一句话

> 头足纲的全部特征围绕一条主线演化：**「足前移到头部 → 腕 + 漏斗 = 运动与捕食装置；外套膜密闭成腔 → 喷射推进；壳内化再退化 → 换取速度」**——由此配套出**闭管循环 + 血蓝蛋白 + 巨轴突神经 + 晶体眼 + 变色皮肤**这一整套「软体动物中最高级」的生理体系，生活史则是**快生长、短寿命、一次繁殖**的 r-策略。
