# 第三章 海洋底栖植物——大型底栖藻类（要点提炼）

> 来源：《3-海洋底栖植物-大型底栖藻类.pdf》（71 页课件，华南农业大学《海洋底栖生物学》）
> 主线：**褐藻门（重点）→ 绿藻门 → 红藻门**

---

## 〇、总览

- **底栖植物**包括：单细胞底栖藻类、海藻（大型藻类）、维管植物。
- **大型海藻三大门**：绿藻门（石莼、浒苔）、褐藻门（海带、巨藻）、红藻门（紫菜、江蓠）。
- 课件分三节：**第一节 褐藻门**、第二节 绿藻门、第三节 红藻门。

---

## 第一节 褐藻门（Phaeophyta）

### 1. 主要特征

| 项目 | 内容 |
|---|---|
| 种类数 | 约 **1500 多种**；大多数海产，极少数产于淡水 |
| 藻色 | 一般呈**棕褐色**，故称褐藻 |
| 大小 | 差异极大：水云目、黑顶藻目需显微镜观察；巨藻可长达 **100～200 m** |

- 同一种类不同生长时期大小也相差很大：海带孢子体可长达 **3～4 m**，而配子体需在显微镜下才能看清。
- 褐藻**全部为多细胞体，无单细胞种类**。

### 2. 体制（三种）

| 体制      | 基本特征                                      | 代表类群               |
| ------- | ----------------------------------------- | ------------------ |
| **异丝体** | 最原始；藻体分匍匐部与直立部；直立部为单列细胞分枝体，匍匐部为匍匐假根，固着于基质 | 水云目                |
| **假膜体** | 较异丝体高级；许多藻丝胶粘在一起，外形似膜状；分单轴（一个中轴）与多轴（多个中轴） | 酸藻目、索藻目、毛头藻目       |
| **膜状体** | 高级进化；外形已有类似根、茎、叶或气囊的分化；内部细胞多向分裂形成数层细胞     | 黑顶藻目、网地藻目、海带目、墨角藻目 |

### 3. 细胞结构

**（1）细胞壁**

- 内层：**纤维素**；外层：**褐藻酸**和**硫酸多糖**。
- **褐藻酸**：存在于细胞间质中，使藻体柔韧、帮助对抗失水，并有助于铁离子交换；是褐藻细胞壁主要成分之一，有的物种可达藻体干重的 **35%**。
- **硫酸多糖**即藻胶，存在最广泛的是**岩藻多糖**。

**（2）原生质体**：1 个或多个小液泡，单核。

**（3）色素、色素体与贮存物质**

- 色素：**叶绿素 a、c**，β-胡萝卜素，叶黄素，**褐藻素（岩藻黄素、墨角藻黄素）**，使藻体呈褐色。
- 色素体：盘状、螺旋带状或分枝状，侧生或轴生。
- 贮存物质：主要是**褐藻淀粉**和**甘露醇**。

### 4. 生长方式

**顶端生长、居间生长、毛基生长**三种。

### 5. 繁殖方式

```text
褐藻繁殖
├─ 营养繁殖
│   ├─ 藻体断折
│   └─ 繁殖小枝（如黑顶藻属，二叉/三叉/楔形，脱落后长成新个体）
├─ 无性繁殖
│   ├─ 游孢子（动孢子）
│   └─ 静孢子（不动孢子，n）
└─ 有性繁殖
    ├─ 同配生殖
    ├─ 异配生殖
    └─ 卵式生殖
```

**孢子囊类型（考点）**

| 类型 | 是否减数分裂 | 产物 |
|---|---|---|
| **单室孢子囊** | 减数分裂 | 单倍体（n）孢子 |
| **多室孢子囊** | 无减数分裂 | 二倍体（2n）孢子 |

**三种有性生殖对比**

| 类型 | 配子特点 | 代表类群 |
|---|---|---|
| **同配生殖** | 配子形状、大小相同；最原始 | 水云目、黑顶藻目大多数种类 |
| **异配生殖** | 形状相似，雌配子比雄配子大；雄配子运动能力强；仅少数种类 | — |
| **卵式生殖** | 雌雄配子形状、大小明显不同：精子小，具 **2 条侧生鞭毛**（一前一后）；卵大、无鞭毛、不能运动 | 酸藻目、海带目、网地藻目；一般雌雄异体 |

> 异配生殖补充：雄配子囊比雌配子囊小；雌配子含数个色素体，雄配子一般只含 1 个色素体；结合时雄配子活泼运动，雌配子迟钝或无运动能力。

### 6. 生殖结构

- **生殖托 + 生殖窝**，为褐藻中较高级种类（墨角藻目）特有。
- **生殖托**：植物体分枝顶端膨大所形成；精子囊和卵囊都凹陷于生殖托的**生殖窝**中。
- 类型：**雌雄同窝、雌雄异窝、雌雄异体**，是分属、分种的依据之一。

### 7. 生活史

褐藻一般有**世代交替**（**墨角藻目除外**）。

| 类型 | 特点 | 举例 |
|---|---|---|
| **同形世代交替**（等世代交替） | 配子体与孢子体形状相同、大小相等，非生殖期外形不易区分 | 水云 |
| **异形世代交替**（不等世代交替） | 配子体与孢子体形状、大小不等；多数孢子体大、配子体小 | 海带 |
|  | 少数孢子体小、配子体大 | 萱藻 |

### 8. 分类

依据**生活史、藻体构造、生长方式、色素体中有无淀粉核**，褐藻分为 **13 个目**。

### 9. 常见经济种类

#### （1）水云目——褐绒藻

- 形态：体黄褐色，丝状，单列细胞，不规则多方向分枝，丛生，高约 **3～10 cm**；基部向下延伸许多丝状假根形成固着器，附着岩石上。
- 生长方式：**毛基生长或间生长**。
- 细胞：单核，多个盘状色素体，上有淀粉核。
- 生活史：**同形世代交替**。

#### （2）索藻目——铁钉菜

- 形态：藻体直立，暗褐色；固着器盘状，有短柄。
- 生长方式：**居间生长**。
- 生活史：**异形世代交替**（孢子体大于配子体）。
- 分布：浙江沿海均有，生长在低潮带波浪冲击的岩礁上。

#### （3）网地藻目——网地藻

- 形态：藻体扁平、膜状，借厚毡状基部固着岩石；直立体通常在同一平面上分枝。
- 生长方式：**顶端生长**；分生组织位于顶端，每一分枝顶端具 1 个顶细胞；有或无中肋。
- 生活史：**同形世代交替**，雌雄异株，孢子体与配子体形态相似。
  - 孢子体仅产生**单室孢子囊**，整个或部分突出藻体表面，每个不动孢子囊产生 **4 或 8 个不动孢子**。
  - 雄配子体产生精子囊，通常成群，精子具**单条鞭毛**；雌配子体产生卵囊，每个卵囊产生 1 个卵。
  - 有或无隔丝。

#### （4）海带目（Laminariales）

- 本目均为**大型膜状体**，单条或分枝带状、圆柱状至扁平状；有固着器、柄、叶片分化，内部构造较复杂。
- 生长方式：**居间生长**，分生组织位于柄部和叶片之间。
- 生活史：**异形世代交替**（大孢子体、小配子体）。
- 约 **4 科 30 多属**，主要产于寒带及亚寒带海中，仅少数生活于暖流海中。

**① 绳藻科**

- 藻体无茎、叶之分，为一条不分枝的圆柱体，中空，但处处有隔膜，分隔成许多体腔；基部为盘状固着器。
- 藻体褐色，丛生，由小盘状固着器上直立长出，**居间生长**；高 **0.3～3 m**，不分枝，呈单条绳状，有时扭曲呈螺旋状。

**② 海带科**

- 孢子体大型，由**固着器、柄部、叶片**三部分组成；柄部一般不分枝。
- 叶片形状多样：简单或复杂、全缘或有缺刻、中肋或有或无、表面光滑或粗糙，有时具小孔。
- 内部由**髓、皮层、表皮层**三部分组成；有些种属具粘液腺、粘液腔道和毛窠。
- 均有明显**异形世代交替**；我国主要只有 1 属。

**海带属 *Laminaria***

- 藻体明显分为固着器、柄部、叶片三部分；固着器假根状或盘状；叶片单条或深裂为掌状；有的种类柄部和叶片具粘液腔道。
- 生活史有明显异形世代交替。
- 我国只有**海带 *Laminaria japonica*** 1 种。

**海带的价值**

- 食用与营养：俗称“长寿菜”，常吃海带抗辐射；可做海带丝、海带结、海带豆腐汤、海带煲绿豆、海带炖肉等。
- 工业原料“**海带三大宝**”：
  1. **碘**：碘酒、碘仿（消毒）；工业上用于染料合成和无机碘化物制备。
  2. **褐藻胶及其衍生物**：纺织、印染、医药、食品。
  3. **甘露醇**。

**③ 巨藻科**

**巨藻 *Macrocystis pyrifera***

- 柄部反复分枝，长达 **30～50 m**；每个分枝顶端形成一新叶片。
- 每片叶宽 **5～9 cm**、长 **3～5 m**，叶缘有锯齿状突起，叶基部具一个**纺锤形气囊**。
- 多年生，最长寿命可达 **12 年**；一般长数十米。
- 冷水性，最适水温 **8～20 ℃**，生长在潮下带水深 **6～30 m** 的岩石上；生长茂盛处叶片可铺满几百平方公里海面。

**海囊藻 *Nereocystis luetkeana***

- 孢子体为**一年生**大型褐藻；基部有分枝假根状固着器。
- 柄长达 **20～25 m**，不分枝，圆柱状；柄上方逐渐宽展成**球形气囊**。
- 气囊上面着生 **4 个**短而扁平、有 4～5 次双叉分枝的枝，每一分枝末端长出线形叶片，叶片平面光滑。

**巨藻的生态功能**

- 许多生物在巨藻叶片中寻找庇护所或食物：海豹、海狮、鲸、海獭、海鸥、燕鸥、雪鹭、大蓝鹭、鸬鹚和滨鸟等。
- 很少有动物直接吃巨藻活叶，但巨藻叶片分解物形成大颗粒和有机分子，为悬浮摄食者和沉积摄食者提供食物。
- 许多动物带幼崽在巨藻中躲避捕食者或抵御风暴湍流。

**巨藻的经济价值**

- 食用；
- 富含碘和钾，可作化工原料；
- 微生物发酵产生甲烷等可燃性气体，制造酒精、丙酮等；
- 提取甘露醇，具医用价值。

**④ 翅藻科（Alariaceae）**

- 孢子体大型，分假根、柄及叶片三部分，叶片具裂片；**居间生长**。

**翅藻属 *Alaria***：孢子体大型，多年生；基部有较小分枝纤维状假根，其上为不分枝短柄（圆柱形或扁压实质）；柄上端有长大、全缘而薄的叶片，中央有一条中肋，叶面平滑，通常具毛丛；**孢子叶生于柄部侧面**。

**昆布属 *Ecklonia***：孢子体分固着器、柄、叶片三部分；固着器假根状或形成匍匐部分；柄圆柱状、不分枝；叶片单条或羽状以至复羽状分枝，叶缘多有粗锯齿；粘液腔道 1～2 层；游孢子囊群生于叶片两面。我国产的种类为**昆布**。

**裙带藻属 *Undaria***：幼期为卵形或长叶片状、单条；生长中逐渐羽状分裂，有隆起的中肋或加厚似中肋状；有毛窝而无粘液腔，但有粘液腺细胞；成熟时孢子囊形成在柄部两侧延伸出的**褶皱状孢子叶**上；繁殖与生活史似海带。我国常见 1 种（裙带菜）。

#### （5）墨角藻目（Fucales）

- 藻体为**多年生孢子体**，二叉式分枝，枝向一方或四方辐射生长。
- 有表皮、皮层、髓部及气囊等分化。
- 生长方式：**顶端生长**。
- 生活史：**无配子体**（无世代交替）。

**马尾藻科（Sargassaceae）**

- 藻体大型、多年生、分枝状，已分化成**固着器、茎和叶**三部分。
- 由主轴放射状分枝或两侧分枝互生，扁平至圆柱形，其上有**气囊或生殖托**。

**半叶马尾藻 *Sargassum hemiphyllum***：藻体高 **10～50 cm**；固着器假根状，有匍匐枝，自其上生出主干；主干极短，上生主枝。

**羊栖菜 *Sargassum fusiforme***

- 俗称**鹿角尖、海大麦**，暖温带性海藻。
- 分布：我国北起辽东半岛，南至雷州半岛均有，以**浙江沿海最多**；喜丛生在浪大流急的礁石上。
- 株高一般 **30～50 cm**，最高可达 **200～220 cm**。
- 藻体由假根、茎、叶片和气囊组成；假根为吸盘状固着器，茎为直立圆柱状主枝；叶片、气囊北方呈锯齿状，南方呈线形或棒状；鲜品黄褐色，干品黑色。
- 生活史：**只有双倍体孢子体阶段，无明显单倍体配子体阶段**。

## 第二节 绿藻门（Chlorophyta）

### 1. 主要特征

| 项目 | 内容 |
|---|---|
| 种类数 | 约 **8600 种**；绝大多数产于淡水，极少数海产 |
| 常见物种 | 石莼、浒苔、礁膜、羽藻、蕨菜、伞藻等 |
| 藻色 | 一般呈**草绿色** |
| 体制 | 单细胞、群体、丝状体、异丝体、膜状体、管状体 |
| 色素 | 叶绿素 **a、b**，α、β-胡萝卜素和叶黄素；**叶绿素占优势** |
| 光合产物 | **淀粉**，细胞内具**淀粉核** |
| 细胞壁 | 内层**纤维素**，外层**果胶质** |
| 繁殖 | 营养繁殖、无性繁殖、有性繁殖 |

### 2. 常见代表

**浒苔属 *Enteromorpha***

- 藻体黄绿色，**中空管状**，由一层细胞组成，单条或分枝，呈带状或叶片状，边缘中空。
- 基部细胞向下延伸出许多假根丝，组成盘状固着器。
- 世界性温带性海藻，我国沿海常见 2 种。

**石莼属 *Ulva***

- 藻体黄绿色，为**卵圆形叶状体**，边缘稍呈波状。
- 基部细胞由两侧细胞向下延伸出许多假根丝组成固着器。
- 产于我国沿岸，东海、南海较习见，黄渤海较稀少。常见如**孔石莼**。

**礁膜属 *Monostroma***

- 藻体绿或黄绿色，**单层细胞**，边缘呈波状，片状、膜质，薄软而多少粘滑，退潮后粘贴于岩石上。
- 植物体偶尔断裂，每个断片可长成完整植物体，或具生长能力的片段脱离母体后长成新个体。
- 质软味美，可鲜食或晒干储存食用，并具药用价值。

## 第三节 红藻门（Rhodophyta）

### 1. 主要特征

| 项目 | 内容 |
|---|---|
| 种类数 | 约 **4410 种**；绝大多数海洋，且喜居深海 |
| 常见种类 | 紫菜、石花菜、红毛藻、海萝、鹧鸪菜等 |
| 体制 | 少数单细胞或群体，多为多细胞群体；主要包括简单丝状体和假薄壁组织的叶状体或枝状体 |
| 生长方式 | 多为**顶端生长**，亦有居间生长或分散生长 |
| 细胞壁 | 内层**纤维素**，外层**藻胶**（琼胶、海萝胶、卡拉胶） |
| 色素 | 叶绿素 a、b，β-胡萝卜素和叶黄素；还有**藻红素和藻蓝素**，其中**藻红素占优势**，藻体一般呈红色或紫色 |
| 贮存物质 | **红藻淀粉**（红藻特有的非溶性多糖），遇碘变成**紫红色** |
| 繁殖 | 营养繁殖、无性繁殖、有性繁殖 |

### 2. 常见代表

**紫菜属 *Porphyra***

- 植物体深紫红色或浅黄绿色，**薄膜叶片状**；基部楔形或心脏形，基部细胞向下延伸成假根丝状固着器。
- 多生长在面朝东、风浪较大的岩礁潮间带。
- 主要养殖种类：**条纹紫菜、坛紫菜、甘紫菜**等。
- 食用价值高，富含碘，营养丰富，滋味鲜美，有“**海苔之王**”之称。

**石花菜 *Gelidium* 属**

- 藻体紫红色或棕红色；基部有固着器，生长在海底岩石。
- 植物体扁平直立、丛生，由主枝和大小不等的分枝组成，呈**羽状分枝**。
- 生长于我国黄海、渤海、东海等海域。
- 除食用外，对降血脂、降血压、抗肿瘤、抗凝血等有不同程度作用；是制造**琼胶**的主要原料。

## 四、三门比较（核心考点）

| 项目 | 褐藻门 | 绿藻门 | 红藻门 |
|---|---|---|---|
| 种类数 | 约 1500 多种 | 约 8600 种 | 约 4410 种 |

## 五、易混点与记忆要点

1. **褐藻无单细胞种类**；绿藻有单细胞、群体等体制。
2. **褐藻除墨角藻目外**都有世代交替；墨角藻目生活史中**无配子体**。
3. **单室孢子囊进行减数分裂**（产 n 孢子）；**多室孢子囊不减数**（产 2n 孢子）。
4. 同形世代交替代表**水云**；异形世代交替代表**海带**（孢子体大）与**萱藻**（配子体大）。
5. 生长方式对应：水云——毛基/间生长；铁钉菜——居间生长；网地藻——顶端生长；海带——居间生长；墨角藻——顶端生长。
6. 褐藻“三宝”：**碘、褐藻胶、甘露醇**。
7. 红藻特有贮存物：**红藻淀粉**（遇碘紫红色）；红藻胶质：**琼胶、海萝胶、卡拉胶**。
8. 羊栖菜生活史**只有二倍体孢子体**，无明显的单倍体配子体阶段。
