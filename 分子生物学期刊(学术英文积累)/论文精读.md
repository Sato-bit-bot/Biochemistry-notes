# 论文精读：FFCNN 用于复杂基质中多组分微塑料的识别

> **出处**：Chen X, Wang H, Shao W, et al. *Environ. Sci. Technol.* 2026, 60, 16662–16675
> **DOI**：10.1021/acs.est.6c05467
> **机构**：南京大学 环境学院 / 计算机科学与技术学院
> **基金**：国家自然科学基金（22241601）

## 一、结构化概览

### 1. 解决的核心问题

环境微塑料（MPs）通常以**多组分混合物**形式存在，传统拉曼光谱方法只能做**单标签分类**（一个样品 = 一种塑料），无法同时识别混合物中的多种成分。此外，环境样品中存在老化、添加剂、有机质干扰等问题，导致光谱信噪比低、特征峰模糊。

### 2. 提出的方案

开发了 **FFCNN（Fast Fourier Convolutional Neural Network）** + **HFM（Hierarchical Feature Mapping）** 框架：

| 组件 | 功能 |
|------|------|
| **FFCNN** | 基于快速傅里叶卷积的神经网络，从原始拉曼光谱中提取多尺度特征，实现多标签分类（同时识别多种塑料成分） |
| **HFM** | 分层特征可视化工具，逐层展示网络"学到了什么"，解释模型决策过程 |

### 3. 核心结果

- **多标签分类 Macro F1-score**：93.6%（比第二名随机森林高 10.18%）
- **22 个环境样品验证**：与热裂解-气质联用（Pyr-GC/MS）交叉验证一致率 **100%**
- **检测下限**：约 1 μm（≥1 μm 的颗粒检测率 93.3–100%）
- **光老化鲁棒性**：96 h 人工光老化后分类准确率仍 >100%

```
1. Introduction → 问题背景 + 现有方法不足

```

## 二、逐段核心方法解读

### 2.1 问题定义：多分类 vs 多标签

| 概念 | 含义 | 通俗类比 |
|------|------|----------|
| **多分类（Multiclass）** | 每个样品只属于**一个**类别 | 水果分类：这个是苹果还是梨？只能选一个 |
| **多标签（Multilabel）** | 每个样品可以**同时属于多个**类别 | 水果沙拉：里面既有苹果又有梨，需要全部标出 |

**设计动机**：真实的环境微塑料混合物中，PP(聚丙烯)、PE(聚乙烯)、PS(聚苯乙烯)、PVC(聚氯乙烯)、PET (聚对苯二甲酸乙二醇酯) 可能同时存在，单标签分类无法应对。FFCNN 的输出层使用 **sigmoid 激活**（而非 softmax），允许每个成分独立输出概率。

### 2.2 核心架构：FFC 模块

**问题**：传统 CNN 的卷积核是**固定大小**的局部操作，难以同时捕捉：
- 拉曼光谱中的**局部峰形**（如特征峰的精细形状）
- **全局背景变化**（如荧光基线漂移、噪声）

**解决方案——快速傅里叶卷积（FFC）**：

每个 FFC 模块包含**两条并行路径**：

```
输入特征图
    ├── 局部/空间路径 → 常规卷积（捕获局部峰形）
    └── 全局/频谱路径 → FFT 变换到频域 → 频域卷积 → IFFT 回到空间域
              ↓
         两路信息交换（跨尺度融合）
              ↓
         输出特征图
```

**通俗解释**：就像一个人同时用"放大镜"（局部卷积）看光谱的细节峰，又用"望远镜"（全局频域操作）看整体趋势，然后把两种视角的信息综合起来。

**网络整体结构**（图 1）：
- CNN 骨干网络在第二层最大池化后嵌入 **3 层 FFC 模块**
- 每个 FFC 模块基于 **ResNet 残差连接**思想：身份映射 + 残差映射并行
- 输出层：C 个神经元 + sigmoid → 每个 MP 成分的独立概率

### 2.3 HFM 分层特征映射（可解释性工具）

**目的**：打开"黑箱"，让人类看到模型每一层在关注光谱的哪些区域。

**三步层次**：
1. **浅层**：捕获低级特征（边缘、纹理 → 光谱中的尖锐峰）
2. **中间层**：提取更抽象的特征（形状、结构元素 → 峰的组合模式）
3. **深层**：捕获高级语义特征（物体形状、抽象模式 → 成分的整体光谱指纹）

**关键优势**：HFM 是**标签无关的**（label-agnostic），不依赖于特定类别，适用于多标签识别任务。相比之下，Grad-CAM 等方法在多标签场景中会混合不同类别的响应，产生误导。

### 2.4 样品制备与光谱采集

**样品来源**：
- 5 种纯品 MP（PP、PE、PS、PVC、PET）
- 含添加剂的商业 MP 产品
- 实验室配制的 MP 混合物
- 南京地区水体和土壤采集的环境样品（135 个）

**光谱采集条件**：
- 仪器：XploRA Plus 共焦拉曼光谱仪（HORIBA）
- 激光波长：532 nm，功率 100 mW
- 物镜：50×（NA = 0.75）
- 采集时间：10 s
- 光谱范围：500–3500 cm⁻¹
- 实际横向分辨率：0.93 ± 0.08 μm（刀口法测量）

**数据库构成**：
- 纯品 MP：500 组 × 5 种 = 2500 组光谱
- 商业 MP（含添加剂）：500 组
- MP 混合物：500 组
- 环境 MP 混合物：500 组
- 开源库 SloPP：200 条
- **总计 3600 条光谱**

## 三、关键概念规范解释

### 3.1 拉曼光谱（Raman Spectroscopy, RS）

| 项目 | 说明 |
|------|------|
| **原理** | 激光照射样品 → 分子振动产生非弹性散射（拉曼散射）→ 散射光频率偏移反映分子键的振动模式 |
| **输出** | 强度 vs 拉曼位移（cm⁻¹）的谱图，如同分子的"指纹" |
| **优势** | 无需复杂前处理、空间分辨率高、水干扰小 |
| **劣势** | 荧光干扰（来自有机质、添加剂）、单标签分类局限 |

**通俗例子**：每种塑料的拉曼光谱就像每个人的声纹——虽然都是"嗡嗡声"，但频率组合不同，理论上可以区分。但当多种声音混在一起（混合物），就很难分辨了。

### 3.2 五种目标微塑料的特征峰

| 塑料 | 关键特征峰区域 | 特征峰数 | 区分要点 |
|------|--------------|---------|---------|
| **PE** | 1000–1500 cm⁻¹（4 个）+ 2800–3000 cm⁻¹（2 个强峰） | 6 | CH₂ 摇摆、弯曲振动 |
| **PP** | 500–1500 cm⁻¹（7 个）+ 2800–3000 cm⁻¹（3 个强峰） | 10 | 比 PE 多 CH₃ 弯曲（~1458 cm⁻¹）和 C-C 伸缩（~1152 cm⁻¹） |
| **PS** | 600–1700 cm⁻¹（8 个）+ 2800–3100 cm⁻¹（2 个强峰） | 10 | 苯环呼吸振动（~1001 cm⁻¹）、环面内弯曲（~1032 cm⁻¹） |
| **PVC** | 600–1500 cm⁻¹（6 个） | 6 | C-Cl 伸缩（~636, 696 cm⁻¹）是独有的 |
| **PET** | 600–1700 cm⁻¹（多个） | 多 | C-O 伸缩（~1728 cm⁻¹）、苯环 C-C 伸缩（~1615 cm⁻¹） |

**难点**：PP 和 PE 结构相似（都是聚烯烃），CH 伸缩峰几乎重叠（~2722, ~2843, ~2881 cm⁻¹），主要差异在指纹区。

### 3.3 评估指标

#### F1-score

$$F1 = 2 \times \frac{Precision \times Recall}{Precision + Recall}$$

| 指标 | 含义 | 通俗解释 |
|------|------|---------|
| **Precision（精确率）** | 预测为正的样本中，真正为正的比例 | "说是苹果的，确实是苹果"的比例 |
| **Recall（召回率）** | 真正为正的样本中，被正确预测的比例 | "所有苹果中，被找出来的"比例 |
| **F1-score** | 二者的调和平均 | 综合平衡精确和召回 |

**为什么选 F1 而非 Accuracy**：微塑料混合物的类别分布不均衡，F1 对少数类更敏感。

#### 多标签分类的阈值设定

- 当混合物中成分数量 **≤ 3**：概率 > **0.5** 即判定存在
- 当成分数量 **> 3**：阈值降至 **0.2**（经验值，基于前 30 轮测试优化）

**动机**：成分越多，单个成分的信号越弱，阈值需要降低以避免漏检。

### 3.4 误识别指数（Misidentification Index, MI）

用于量化多标签分类中模型预测错误的程度。MI 越小，模型识别真实成分的准确率越高。

各模型 MI 排序：ResNet (0.63) > DenseNet (0.58) = CNN (0.58) > **FFCNN (0.51)**

## 四、公式/数学思想说明

### 4.1 FFC 的核心思想（频域操作）

虽然文中数学推导在 Supporting Information（Text S5–S6）中，但核心思想可以概括为：

**目标**：将空间域的卷积操作转换到频域，利用 FFT 实现**全局感受野**。

**变量**：
- 输入特征图 $X \in \mathbb{R}^{C \times L}$（C 个通道，L 个光谱点）
- 频域权重 $W_f$：在频域中对所有频率分量进行加权
- 输出 $Y = \mathcal{F}^{-1}(W_f \cdot \mathcal{F}(X))$

**设计动机**：
- 传统卷积的感受野 = 卷积核大小（如 3×1），只能看局部
- FFT 将整个序列变换到频域 → 频域的逐元素乘法等价于空间域的**全局卷积**
- 同时保留局部路径，实现"局部 + 全局"的跨尺度融合

**通俗类比**：传统卷积像通过一个小窗户看风景（只能看到局部），FFC 则是先用无人机航拍全景（FFT），再用放大镜看细节（局部卷积），最后把两张图叠在一起分析。

### 4.2 残差连接

$$Y = F(X) + X$$

- $F(X)$：残差映射（学习"差异"）
- $X$：身份映射（保留原始信息）
- **目的**：防止深层网络的梯度消失，确保关键光谱信息不丢失

### 4.3 Sigmoid 多标签输出

对于 C 个 MP 类别，输出层第 $c$ 个节点：

$$\hat{y}_c = \sigma(z_c) = \frac{1}{1 + e^{-z_c}}$$

- $\hat{y}_c \in (0, 1)$：第 $c$ 种 MP 成分存在的概率
- 各成分独立判断，互不排斥

### 图 2：混淆矩阵对比

**实验目的**：对比 FFCNN 与 CNN、ResNet、DenseNet 在不同任务上的表现。

**关键结论**：

| 任务 | FFCNN | CNN | ResNet | DenseNet |
|------|-------|-----|--------|----------|
| 多分类（无变形光谱）| 97.6% | 89.6% | 91.8% | 92.8% |
| 多分类（含变形光谱）| 97.6% | ~85%（↓4%+）| ~87%（↓4%+）| ~88%（↓4%+）|

**核心发现**：去除干扰光谱后，其他模型准确率下降 ≥4%，FFCNN 仅变化 1% → FFC 内置滤波器自动抑制了噪声和孤立尖峰。

- **(a–c)** 混淆矩阵：单组分准确率 96.8–99.2%，双组分 91.7%，多组分组件级召回率 89.2%

**实验目的**：在真实环境样品上测试。

- FFCNN 识别准确率 **100%**（22/22）
- KnowItAll 商业库有 6 个样品无法识别

## 六、论文逻辑链

```
现实问题
  环境微塑料以多组分混合物形式存在
         ↓
传统方法局限
  拉曼光谱 → 单标签分类 → 无法识别混合物
  传统 ML → 过拟合 + 抗噪性差
  CNN → 感受野受限 + 黑箱不可解释
         ↓
解决方案
  1. FFCNN：FFC 模块实现"局部+全局"跨尺度特征提取
  2. 多标签输出：sigmoid 允许同时输出多种成分概率
  3. HFM：逐层可视化，解释模型关注的光谱区域
         ↓
验证路径
  ① 数据库：3600 条光谱（纯品 + 老化品 + 添加剂 + 混合物 + 环境样品）
  ② 模型对比：FFCNN vs CNN/ResNet/DenseNet/传统 ML
  ③ 环境样品：22 个样品，FFCNN 100% vs Pyr-GC/MS 100% vs KnowItAll 73%
  ④ 鲁棒性：光老化、空间分辨率、尺寸依赖性检测
         ↓
结论
  FFCNN + HFM 提供了一个快速、准确、可解释的环境微塑料混合物识别框架
```

## 七、局限性与未来方向

| 局限 | 说明 | 可能的改进方向 |
|------|------|--------------|
| **聚合物覆盖有限** | 仅覆盖 PP、PE、PS、PVC、PET 五种，未涵盖 PMMA、PA、PC 等 | 扩展光谱库，引入更多聚合物类型 |
| **尺寸范围** | 0.5–20 μm，纳米级塑料未涉及 | 结合表面增强拉曼（SERS）或更长采集时间 |
| **极端老化泛化** | 极端光降解、热氧化、生物降解导致的光谱剧变需要系统验证 | 构建更全面的老化光谱数据集 |
| **可解释性的间接性** | HFM 展示"模型关注哪里"，但不能精确解释"为什么" | 建立模型决策与化学键振动的直接定量联系 |
| **加速老化的近似性** | 汞灯与自然光谱不完全匹配，96 h ≈ 28 天仅为量级估计 | 采用更接近太阳光谱的光源，建立材料特异性加速因子 |
| **检测下限** | <1 μm 颗粒拉曼信号不足 | 探索 SERS、受激拉曼等增强技术 |

## 八、个人评价

### 亮点
1. **方法创新性强**：将 FFT 引入拉曼光谱 CNN 分析，解决感受野受限问题，思路新颖
2. **实用价值高**：无需复杂前处理即可识别混合物，100% 环境样品验证准确率
3. **可解释性好**：HFM 工具为深度学习在环境分析中的应用建立了信任基础
4. **数据库全面**：3600 条光谱覆盖纯品、老化品、添加剂、混合物和环境样品

### 不足
1. **验证规模偏小**：环境样品仅 22 个，统计效力有限
2. **缺乏与其他光谱技术的对比**：未与红外光谱（FTIR）等方法进行系统对比
3. **商业转化路径不明确**：未讨论模型的计算效率、部署成本等实际问题
