# PPT 大纲与设计规范：Reading the Enemy's Blueprint

> **底稿**：[[分子生物学期刊(学术英文积累)/论文精读2|论文精读2]]
> **讲稿**：[[分子生物学期刊(学术英文积累)/论文精读2-演讲稿|论文精读2-演讲稿]]

> **目标时长**：5 分钟 / **页数**：14 页（含封面与致谢）
> **场合**：Journal Club 口头报告

## 一、总体判断：先解决三个冲突

| 冲突 | 说明 | 处理 |
| --- | --- | --- |
| **页数 vs 时长** | 模板 15 页，5 分钟 = 平均 20 秒/页，必翻得慌 | 压到 **14 页**：删 1 页、合并 2 处、新增 2 页 |
| **模板缺 2 处关键内容** | 图页只有 Fig 1、Fig 2&3，**没有 Fig 4（毒力因子）**，也没有"疫苗 + 育种"应用页 | 新增 P8（Fig 4 + 比较基因组学）、P9（分泌系统）、P10（双栏应用页） |
| **数据口径不一致** | 演讲稿写 WGS 沉积高峰"2015–2020"，模板写"2016 年峰值 ~12 篇/年" | 统一采用模板中更具体的表述：**2016 年峰值，约 12 个基因组/年** |

### 与讲稿的时间对齐（核心约束）

讲稿本身已有 `[0:00]`–`[4:45]` 八个段落。**PPT 分页必须落在讲稿段落边界上**，不允许"讲到一半换页"。因此分页按下列八段切分：

```
Opening hook → The paper → Old methods fail → What the review did
→ Mechanism → Applications → Limits → Closing
```

| 项 | 内容 |
| --- | --- |

### P4 · 04 / WHAT IS THIS PAPER ABOUT

| 项 | 内容 |
| --- | --- |
| **标题** | `Scope & Model System` |
| **左栏** | Scope 一句 + Model system 一句（79 species / 4 phyla / 13 genera） |

| **右栏** | graphical abstract 图（模板已嵌 Picture 5） |
| **图注** | `From pathogen identification to disease resistance` |
| **设计要点** | 这五个词就是全场骨架，用箭头暗示因果与递进，而不是目录 |
| **讲述钩子** | *"Its central claim is simple: genomics changed what we can know, and how fast."* |

### P5 · 06+07 合并 · The Gap（全场最重要一页）

| 项 | 内容 |
| --- | --- |
| **标题** | `Why the Old Toolkit Fails` |
| **主体** | **五张卡片横向一字排开**，每张 = 一个词 + 一句短注 |

| 卡片 | 短注 |
| --- | --- |
| **Slow** | days to weeks |
| **Insensitive** | fastidious species won't grow |
| **Poorly specific** | look-alike species |
| **Blind to mixed infections** | find one, miss three |
| **No genetic information** | no virulence / AMR genes |

| 项 | 内容 |
| --- | --- |
| **底部横条** | 高对比色块，内文 `Phenotype → Genotype` |
| **为什么是这页** | 讲稿 [1:00] 段的重音落在"phenotype vs genotype"，屏幕上必须同句出现 |
| **视觉纪律** | 五卡等宽等高、间距 0.3"；**不要用项目符号列表** |
| **讲述钩子** | *"Culture, biochemical testing, MALDI-TOF — all useful. But there are five limits."* |

## 五、视觉与排版规范

### 5.1 配色（基于模板深蓝主调）

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 主色 | `065A82` 深海蓝 | 标题栏、左侧竖条、P1/P14 底色 |
| 辅色 | `1C7293` 青 | 卡片底、图标色圈、次级色块 |
| 中性 | `F2F4F5` 浅灰 | 内容页背景 |
| 强调 | `E7E8D1` 沙金 | 数字卡片、`Phenotype → Genotype` 横条 |
| 文字 | `212121` 深灰 | 正文（不用纯黑） |

**避免**：默认 Office 蓝、多于三色的图表配色、红绿并置（对色觉障碍不友好）。

### 5.2 母题（motif）

全篇**只重复一种视觉元素**：

```
左侧 101600 EMU 窄竖条 + 板块标签下方的 1524000 EMU 细连线
```

（模板已有此结构，无需新增）**不要**再添加标题下划线、页眉装饰色带 —— 两套装饰线会打架。

### 5.3 字体

| 层级 | 字体 | 字号 |
| --- | --- | --- |
| 页面标题 | Trebuchet MS Bold | 36–44pt |
| 板块标签（`08 / FIGURES`） | Calibri Bold, 全大写, 字距 +50 | 20–24pt |
| 卡片小标题 | Calibri Bold | 18–20pt |
| 正文 | Calibri | 14–16pt |
| 图注 | Calibri Italic, 40% 灰 | 10–12pt |
| 大数字 | Trebuchet MS Bold | 60–72pt |

### 5.4 网格与间距

- 页边距 **0.5" 最小**（模板统一从 1016000 EMU ≈ 1.11" 起排，保持不变）
- 内容块间距 **0.3"** 或 **0.5"**，全篇只用这两个值
- 卡片等高：同一行五卡必须**完全等宽等高**，用"对齐 + 分布"而非手动拖拽
- 文本框 `margin` 设为 0，否则文字与色块边缘会错位

### 5.5 每页必有的视觉元素

**不允许出现"纯文字页"。** 每页至少具备以下之一：

- 图片（P3 无图 → 用**两枚色块 + 机构名**充当视觉锚点）
- 图表 / 圆圈图（P6、P7）
- 大数字（P8）
- 图标 + 色圈（P9）
- 双栏色块对比（P10、P12）

### 5.6 图片处理规范

| 图 | 来源 | 处理 |
| --- | --- | --- |
| Fig 1 | 模板 Picture 5 | 原样保留，仅调整尺寸保持比例 |
| Fig 2 / Fig 3 | 模板 Picture 5、Picture 7 | 原样保留，双图同高 |
| **Fig 4** | **需从论文 PDF 补入** | 单独一张，不加边框；若原图元素过多，可裁掉图例另置 |
| Graphical abstract | 模板 Picture 5（P4） | 保留，右栏半幅排版 |

**统一规则**：所有插图 **不加阴影、不加外框**，靠留白分隔；图注统一置于图下方左对齐。

## 六、讲述与翻页对照（防"讲一半翻页"）

| 翻页时机 | 讲稿句子（触发点） |
| --- | --- |
| → P3 | *"The paper is a 2024 review by Olymon and colleagues…"* |
| → P4 | *"Its central claim is simple…"* |
| → **P5** | *"Now, the conventional toolkit is not useless."* |
| → P6 | *"So what did the authors do?"* |
| → P7 | *"Three findings stood out to me."*（第三条说完即翻） |
| → **P8** | *"But sequence alone is not insight."* |
| → P9 | *"Then there is mechanism."* |
| → **P10** | *"Which brings us to application."* |
| → P11 | *"In other words, we are no longer only treating disease…"* |
| → P12 | *"Of course, the authors are candid about the limits."* |
| → P13 | *"So where does that leave us?"* |
| → P14 | *"But let me return to that one-to-two-week culture I began with."* |

> 加粗的三页（P5、P8、P10）是**全场重心**，翻页后应停顿半拍再说第一句。
